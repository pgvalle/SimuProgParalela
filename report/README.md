# Relatório

Compile com Tectonic a partir da raiz do projeto:

```bash
tectonic report/main.tex
```

Ou, dentro do diretório `report/`:

```bash
tectonic main.tex
```

As figuras são carregadas de `plots/` ou `../plots/`, dependendo do diretório de compilação:

- `runtime_errorbars.pdf`
- `speedup_errorbars.pdf`
